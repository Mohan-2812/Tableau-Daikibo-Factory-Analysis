# Daikibo Factory Downtime Analysis

## Project Overview
This project analyzes factory downtime using Tableau to understand machine performance and operational efficiency.

## Objectives
- Analyze downtime across factory locations.
- Identify unhealthy machine conditions.
- Compare machine performance.
- Identify factories with higher downtime.

## Tools Used
- Tableau
- Data Visualization
- Data Analysis

## Key Analysis
- Downtime by Factory
- Machine Health Analysis
- Factory Performance Comparison

## Project Outcome
Created an interactive Tableau dashboard to help identify operational issues and understand factory downtime patterns.
