# Daikibo Factory Operational Performance & Downtime Analysis

## 📊 Project Overview
An interactive Tableau dashboard analyzing factory downtime, machine health, and operational performance using Daikibo manufacturing telemetry data. This project identifies high-downtime facilities and equipment types to help prioritize maintenance schedules.
